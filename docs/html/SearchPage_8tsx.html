function default SearchPage ( { searchType, onClose, onPropertySelect }:SearchPageProps)

Property search page component.

Provides interface to search for properties by location and displays results in list or map view. Integrates with backend API to fetch property data from Zillow.

Executes property search by location. Queries backend API for properties matching the search location.
