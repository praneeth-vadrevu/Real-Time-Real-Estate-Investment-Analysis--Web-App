Real-Time Real Estate Backend Service

A comprehensive Spring Boot backend service for real estate investment analysis. This service provides RESTful APIs for property search, geolocation services, and investment cashflow analysis.

  • Related Documentation

🎯 Overview

This backend service is part of the Real-Time Real Estate Investment Analysis Web Application. It serves as the central API gateway that:

  1. Integrates with Zillow API - Fetches property data, estimates, and market information
  2. Provides Geolocation Services - Uses Google API for geocoding and place search
  3. Performs Investment Analysis - Calculates cashflow projections and investment metrics

Technology Stack

Component Technology Version
Runtime Java 17
Framework Spring Boot 3.2.0
Build Tool Maven 3.8+
JSON Processing Jackson 2.15.x
HTTP Client Java HttpClient JDK 17

✨ Features

🏠 Property Services

  • Extended property search by location
  • Property details retrieval by ZPID
  • Zestimate and rent estimates
  • Property comparables (comps)
  • Price and tax history
  • 3D tours and floor plans

🗺️ Geolocation Services

  • Text-based place search
  • Coordinate-based radius search
  • Address geocoding

💰 Investment Analysis

  • Net Operating Income (NOI) calculation
  • Cap Rate analysis (Purchase Price & FMV)
  • Debt Service Coverage Ratio (DSCR)
  • Cash-on-Cash Return
  • Internal Rate of Return (IRR)
  • Multi-year cashflow projections
  • Equity Multiple calculation

🚀 Quick Start

Prerequisites

  • Java 17 or higher (Download)
  • Maven 3.8+ (Download)
  • RapidAPI Key for Zillow and Google API access

Installation

  1. Clone the repository

    git clone https://github.com/praneeth-vadrevu/Real-Time-Real-Estate-Investment-Analysis--Web-App.git
cd Real-Time-Real-Estate-Investment-Analysis--Web-App/googlemapv2

  2. Set environment variables

    # Windows (PowerShell)
$env:RAPIDAPI_KEY = "your-rapidapi-key-here"

# Linux/macOS
export RAPIDAPI_KEY="your-rapidapi-key-here"

  3. Build the project

    mvn clean install

  4. Run the application

    mvn spring-boot:run

  5. Verify the server is running

    curl http://localhost:8080/api/geo/text?text=test

Using Batch Scripts (Windows)

# Compile the project
compile.bat

# Start the backend server
start-backend.bat

📚 API Documentation

Base URL

http://localhost:8080

Endpoints Overview

Method Endpoint Description
GET /api/properties/search Search properties by location
GET /api/properties/{zpid} Get property details
POST /api/analysis/cashflow Analyze investment cashflow
GET /api/geo/text Text-based place search
GET /api/geo/circle Radius-based search
POST /api/geo/raw Raw geo query

Detailed API Reference

1. Property Search

GET /api/properties/search?location={location}&status={status}&page={page}

Parameters: | Name | Type | Required | Description | |——|——|———-|————-| | location | string | Yes | City, state, or ZIP code | | status | string | No | for_sale, for_rent, sold | | page | integer | No | Page number (default: 1) |

Example:

curl "http://localhost:8080/api/properties/search?location=Santa%20Monica,%20CA&status=for_sale"

2. Property Details

GET /api/properties/{zpid}

Example:

curl "http://localhost:8080/api/properties/20479916"

Response:

{

  "address": "123 Main St, Santa Monica, CA 90401",
  "price": 1500000,
  "bedrooms": 3,
  "bathrooms": 2,
  "livingArea": 1800,
  "yearBuilt": 1985,
  "zestimate": 1450000,
  "rentEstimate": 5500,
  "annualTax": 15000,
  "hoaMonthly": 350
}

POST /api/analysis/cashflow
Content-Type: application/json

Request Body:

  "fmv": 550000,

  "numberOfUnits": 4,
  "vacancyRate": 0.05,

  "insurance": 2400,
  "firstPrincipal": 400000,
  "firstRateAnnual": 0.07,

  "holdYears": 10

Response:

{
  "summary": {
    "rpp": 500000,
    "cashToClose": 100000,
    "noiY1": 35000,
    "capRatePPY1": 0.07,
    "dscrY1": 1.15,
    "cashOnCashY1": 0.085,

4. Geo Text Search

GET /api/geo/text?text={text}&city={city}&state={state}

Example:

curl "http://localhost:8080/api/geo/text?text=white%20house&city=washington&state=DC"

5. Geo Circle Search

GET /api/geo/circle?lat={lat}&lon={lon}&radius={radius}&text={text}

Example:

curl "http://localhost:8080/api/geo/circle?lat=34.0195&lon=-118.4912&radius=5000&text=restaurant"

Common Issues

# Windows
netstat -ano | findstr :8080
taskkill /PID <PID> /F

# Linux/macOS
lsof -i :8080
kill -9 <PID>

2. API Key errors - Verify RAPIDAPI_KEY environment variable is set - Check RapidAPI subscription status - Ensure API key has access to required endpoints

3. CORS errors - Backend includes CORS configuration for localhost:3000 - Add additional origins in CorsConfig.java if needed

1. Introduction

What is this application?

The Real Estate Backend Service is a RESTful API server that powers the Real-Time Real Estate Investment Analysis Web Application. It provides:

  • 🏠 Property Search - Search real estate listings from Zillow
  • 📍 Geolocation - Convert addresses to coordinates and search nearby places
  • 💰 Investment Analysis - Calculate ROI, cashflow, and other investment metrics

Who should use this guide?

  • System Administrators setting up the backend server
  • Developers integrating with the API
  • End Users running the application locally

3. Installation Guide

Step 1: Install Java 17

Windows

  1. Download Java 17 from Adoptium

  2. Run the installer

  3. Verify installation:

    java -version

    Expected output: openjdk version "17.x.x"

macOS

# Using Homebrew

# Add to PATH

sudo apt update

  2. Extract to C:\Program Files\Apache\maven

  3. Add to System PATH:

  4. Verify:

    mvn -version

macOS/Linux

sudo apt install maven

Windows (PowerShell)

7. Troubleshooting

Issue: “Port 8080 already in use”

Solution:

Windows:

# Find the process using port 8080
netstat -ano | findstr :8080

# Kill the process (replace <PID> with actual PID)
taskkill /PID <PID> /F

macOS/Linux:

# Find and kill the process
lsof -i :8080
kill -9 <PID>

Or change the port in application.yml.

Issue: “RAPIDAPI_KEY not found”

Solution: 1. Verify the environment variable is set: powershell echo $env:RAPIDAPI_KEY # Windows PowerShell echo $RAPIDAPI_KEY # Linux/macOS

  1. If empty, set it again (see Configuration section)

  2. Restart your terminal/IDE after setting

Issue: “Connection refused” errors

Solution: 1. Verify the server is running 2. Check if a firewall is blocking the connection 3. Ensure you’re using the correct port

Issue: “401 Unauthorized” from API

Solution: 1. Check if your RapidAPI key is valid 2. Verify you’re subscribed to the required APIs 3. Check if you’ve exceeded API rate limits

Issue: “CORS error” in browser

Solution: The backend allows CORS from localhost:3000 by default. If your frontend runs on a different port, update CorsConfig.java.

8. FAQ

Q: How do I change the server port?

A: Edit src/main/resources/application.yml and change server.port to your desired port.

Q: How many API calls can I make?

A: This depends on your RapidAPI subscription plan. Check your RapidAPI dashboard for limits.

Q: Can I run this on a remote server?

A: Yes! Deploy the JAR file to any server with Java 17 and set the environment variables accordingly.

Q: How do I update the application?

A:

git pull origin main
mvn clean install
mvn spring-boot:run

Q: Is my API key secure?

A: The API key is stored as an environment variable, not in the code. Never commit API keys to version control.

Q: How do I view server logs?

A: Logs are printed to the console. For file logging, add this to application.yml:

logging:
  file:
    name: backend.log

7.2 IRR Calculation (Newton-Raphson)

/**
 * Calculate Internal Rate of Return using Newton-Raphson iteration.
 * 
 * NPV formula: Σ(CFt / (1+r)^t) = 0
 * 
 * @param cashflows List of cash flows (index 0 = initial investment, negative)
 * @param guess Initial guess for IRR
 * @return IRR as decimal (null if not converged)
 */
private static Double irr(List<Double> cashflows, double guess) {
    double x = guess;
    for (int i = 0; i < 50; i++) {  // Max 50 iterations
        double f = 0, df = 0;
        for (int t = 0; t < cashflows.size(); t++) {
            double ct = cashflows.get(t);
            double d = Math.pow(1 + x, t);
            f += ct / d;                              // NPV
            if (t > 0) df += -t * ct / Math.pow(1 + x, t + 1);  // Derivative
        }
        double x1 = x - f / df;  // Newton-Raphson step
        if (Math.abs(x1 - x) < 1e-7) return x1;  // Converged
        x = x1;
    }
    return null;  // Did not converge
}
